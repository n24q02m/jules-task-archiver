## 2026-07-14 - Fix ReDoS Vulnerability in utils.js
**Vulnerability:** A Regular Expression Denial of Service (ReDoS) vulnerability in the `fixJsonControlChars` function due to a regex `/"(?:[^"\\]|\\.)*"/g` with overlapping quantifiers on unbounded string segments.
**Learning:** Using regex with overlapping alternation `([^"\\]|\\.)` inside a greedy repeating group `*` on large, untrusted payloads (like network JSON responses) allows malicious or malformed inputs to cause exponential backtracking, leading to denial of service. Additionally, the original regex failed to process newlines (`\n`) within string literals because the `.` character class does not match line breaks in standard JavaScript regex (without the `s` flag).
**Prevention:** Avoid using complex regex for parsing potentially large and untrusted strings. Instead, use a deterministic, single-pass character loop (state machine) that safely identifies boundaries and applies modifications without backtracking risk. Ensure fast paths (e.g., `!/[\x00-\x1F]/.test(str)`) are retained to prevent performance penalties on clean strings.
